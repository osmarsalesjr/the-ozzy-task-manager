# README — Ozzy - Task Manager

**Versão:** 2.0
**Plataforma:** Bubble.io — Plano Gratuito

## 1. Sobre o Projeto

O **Ozzy - Task Manager** é uma aplicação de gerenciamento de projetos e tarefas desenvolvida em **Bubble.io**, utilizando recursos nativos da plataforma.

A aplicação permite:

* Gerenciamento de projetos;
* Gerenciamento de tarefas;
* Atribuição de responsáveis;
* Controle de status e prioridades;
* Comentários;
* Notificações;
* Histórico de atividades;
* Gerenciamento de usuários;
* Controle de acesso por perfil;
* Dashboard;
* Gerenciamento de perfil.

Os perfis disponíveis são:

* **Administrator** — acesso às funcionalidades administrativas;
* **Member** — acesso às funcionalidades operacionais permitidas.

Novos usuários são criados exclusivamente por um **Administrator**.

## 3. Tecnologias Utilizadas

* **Bubble.io** — Desenvolvimento da aplicação;
* **Bubble Database** — Persistência dos dados;
* **Bubble Workflows** — Regras de negócio e automações;
* **Bubble Option Sets** — Valores fixos da aplicação;
* **Bubble Privacy Rules** — Controle de acesso aos dados.

A solução utiliza recursos nativos do Bubble, mantendo compatibilidade com o plano gratuito.
